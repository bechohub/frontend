Design System: BechoHub
1. Visual Theme & Atmosphere

BechoHub is not a “website” — it is a command center for trade.

The design should feel like:

A control panel for commerce
A high-stakes trading terminal
A platform where money moves, fast and seriously

No fluff. No startup cuteness.

This is:

Industrial. Brutal. Minimal. Powerful.

Core Philosophy:
Dark interface = power + control
Typography = authority
UI = invisible, function-first
Everything should feel expensive and sharp
Key Characteristics:
Deep dark backgrounds (#0A0A0A, not pure black)
High-contrast white text (#FFFFFF / #EAEAEA)
Accent color = aggressive red (#FF2C2C) → action, urgency, deals
Sharp edges (low border radius, mostly 4–8px)
No unnecessary shadows or gradients
Data-first UI (tables, numbers, stats dominate)
Minimal animations → fast, responsive feel
2. Color Palette & Roles
Primary

Background, base UI, dashboard
Hard White (#FFFFFF)
Primary text
Soft White (#EAEAEA)

CTA buttons, highlights, active states
→ Used sparingly for maximum impact
Utility Colors
Success: #00C853
Warning: #FFAB00
Error: #FF3D00
Surfaces
Card BG: #111111
Hover: #1A1A1A
Border: #222222
3. Typography Rules
Font System
Primary: Inter / Satoshi / Helvetica Neue
Backup: Arial, sans-serif
Hierarchy
Role	Size	Weight	Style
Hero	48px	700	Uppercase
Section Title	28–32px	600	Tight
Subheading	18–20px	500	Clean
Body	14–16px	400	Readable
Table/Data	13–14px	500	Dense
Micro	11–12px	400	Muted
Principles
Headlines = bold, confident, slightly tight spacing
Avoid excessive letter-spacing (unlike SpaceX)
Numbers should stand out → financial weight
No playful typography — everything is serious
4. Component System
Buttons
Primary (Action)
Background: #FF2C2C
Text: #FFFFFF
Radius: 6px
Padding: 12px 18px
Hover: darker red

Use for:

Place Order
Send Inquiry
Confirm Actions
Secondary (Ghost)
Background: transparent
Border: 1px solid #333
Text: #EAEAEA
Inputs
Background: #111
Border: 1px solid #222
Text: #FFF
Focus: border turns red
Cards
Background: #111
Border: 1px solid #222
Radius: 8px

Used for:

Product listings
Supplier blocks
Dashboards
Tables (CRITICAL)

Tables are core UI element.

Dense rows
Hover highlight
Clear column hierarchy
Sticky headers

This is not optional — this is your power UI

5. Layout Principles
Grid
12-column grid (web)
Tight spacing → efficient layout
No excessive whitespace
Spacing

Base unit: 8px

Scale:
8 / 12 / 16 / 24 / 32 / 48

Structure
Left sidebar (dashboard)
Top nav (search + profile)
Main content (data heavy)
Philosophy

“Less empty space, more meaningful data.”

6. Depth & Elevation
Level	Use
Base	Page background
Card	Slight elevation via contrast
Active	Border highlight
Modal	Dark overlay
Shadows
Minimal or none
Use contrast instead
7. UX Behavior
Speed is EVERYTHING
Pages must feel instant
No lag, no heavy animations
Interaction Principles
Hover = immediate feedback
Click = instant response
Loading = skeleton UI (not spinners)
Data Priority

Always show:

Price
MOQ
Supplier rating
Availability

Everything else is secondary.

9. Do’s and Don’ts
Do
Keep UI sharp and minimal
Highlight numbers and transactions
Use red only for critical actions
Design for speed and clarity
Make it feel like money is moving
Don’t
Don’t use bright colors randomly
Don’t add unnecessary animations
Don’t make it “fun”
Don’t clutter with too many UI elements
Don’t copy IndiaMART UX
