Bechohub: Exhaustive QA Matrix

Pre-Launch Testing Checklist for the Engineering Team

👨‍💻 Supratim (Senior Dev: Architecture, Security & DB)

1. Database Integrity & Constraints
  • Cascade Deletions

    Manually delete a User from the database. Verify that their SellerProfile, Products, and Inquiries are all deleted automatically via Prisma Cascade rules to prevent orphaned records.

  • Null Reference Handling

    Delete a Product that has active Inquiries. Verify that the Inquiry is NOT deleted, but its productId becomes null (as per onDelete: SetNull in schema), so conversation history isn't lost.

  • UUID Validation

    Attempt to fetch /api/products/12345 (a non-UUID string). Verify the Zod schema catches it and returns a 400 Bad Request before Prisma throws a database error.

2. Security & Penetration Testing
  • Rate Limit Stress Test

    Use a script (or Apache JMeter) to send 150 requests within 1 minute to /api/auth/login. Verify that exactly request #101 receives a 429 Too Many Requests status.

  • CORS Bypass Check

    Use curl from your terminal to hit a protected API endpoint with an Origin: https://malicious-site.com header. Verify the backend explicitly rejects the connection.

  • JWT Forgery

    Take a valid JWT token, paste it into jwt.io, change the user role from BUYER to ADMIN, re-sign it with a fake secret, and send it to the API. Verify the jsonwebtoken verifier rejects it with a 401 Invalid Token.

  • SQL/NoSQL Injection

    Inject {"$gt": ""} or ' OR 1=1;-- into search query parameters or the inquiry message body. Verify Zod sanitizes or rejects it.

3. Image Processing & Storage
  • File Size Limits

    Attempt to upload an 8MB image to the Create Product endpoint. Verify Multer rejects it (since the limit is set to 6MB in config).

  • File Count Limits

    Attempt to upload 12 images at once. Verify it throws an error (limit is 10).

  • Malicious File Types

    Rename an .exe or .sh script to virus.jpg and attempt to upload it. Verify that Sharp (or Multer) rejects the file because the actual MIME type/buffer header is invalid.

👨‍💻 Shinjan (Junior Dev: UI/UX State, Middleware & Edge Cases)

1. Advanced Routing & Middleware
  • Deep Linking Lockout

    Log out completely. Copy a direct link to a deeply nested protected page (e.g., /seller/products/edit/uuid). Paste it into the URL bar. Verify Next.js middleware instantly redirects to /login without flashing the protected UI.

  • Post-Login Redirection

    If a user is redirected to /login from /seller/dashboard, verify that after they log in, they are sent back to /seller/dashboard instead of the generic homepage.

2. Form State & Optimistic UI Updates
  • Double Submit Prevention

    Go to the "Submit Inquiry" form. Click the "Send" button 5 times very fast. Verify that the button enters a loading state immediately after the first click, and only one inquiry is created in the database.

  • Network Failure Recovery

    Turn off your Wi-Fi. Try to submit a product. Verify the frontend displays a graceful "Network Error" toast instead of crashing or showing a white screen.

  • Input Sanitization (XSS)

    In the Product Description or Inquiry message box, type <script>alert('hack')</script>. Verify that when this text is rendered on the frontend later, it is rendered as plain text and the script does not execute.

3. Mobile Web App Constraints
  • Touch Targets

    Open the app on a mobile device (or dev tools). Verify all buttons (especially "Contact Supplier") are at least 44x44px tall to prevent misclicks.

  • Virtual Keyboard UI

    On mobile, tap into the Inquiry text area. Verify the screen scrolls appropriately so the keyboard does not cover the text box you are typing in.

  • Image Carousels

    On mobile, verify product image galleries support swipe-to-scroll rather than forcing the user to click tiny arrow buttons.
